# 🧮 Mental Math Trainer

A web app to practice and improve your mental math skills with
interactive quizzes, math games, reference tables, and more!

🌐 **Live Website:** [mental-math-trainer.vercel.app](https://mental-math-trainer.vercel.app)

---

## ✨ Features

### 🎯 Practice Mode
- Addition, Subtraction, Multiplication, Division
- Exponents & Mixed mode
- 3 Difficulty levels (Easy, Medium, Hard)
- Configurable question count (10, 20, 50, Unlimited)
- Timer, scoring, streak tracking

### 📊 Tables & Reference
- Multiplication tables from 1 to 35
- Addition, Subtraction, Division tables
- Quick reference grid (up to 35×35)
- Searchable tables

### 📐 Laws of Exponents
- 8 exponent laws with formulas & examples
- Powers reference table (base 2-15)
- Dedicated exponent practice mode

### 🎮 Math Games
| Game | Description |
|------|-------------|
| ⚡ Speed Round | 60-second timed challenge |
| 🔗 Number Chain | Chain answers into next question |
| ✅❌ True or False | Quick reaction with 3 lives |
| ❓ Missing Number | Find the missing operand |
| ⚔️ Beat the Clock | Correct +3s, Wrong -5s |
| 🎯 Estimation Master | Points for close guesses |

### 🏆 Gamification
- XP & Level system
- 15 Achievement badges
- Progress tracking with localStorage
